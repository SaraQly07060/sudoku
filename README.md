# Python Sudoku

A classic Sudoku game and solver implemented in Python.

## Features
- Interactive 9×9 Sudoku board
- Row, column, and 3×3 box validation
- Protection for fixed cells
- Clear entries
- Sudoku solver using backtracking
- Completion detection

## Requirements
- Python 3.8+
- No external libraries required

## How to Run
Open `sudoku.py` in Python IDLE or VS Code and run the file.

## How to Play
Enter a move using:

`row column number`

Example: `1 3 4`

Commands:
- `q` — Quit
- `s` — Solve the puzzle
- `c row column` — Clear a cell

## Algorithm
The solver uses recursive backtracking to find a valid solution while respecting Sudoku constraints.
## How to Play

Run the game with Python 3.8 or newer:

python sudoku.py

Follow the on-screen instructions to enter moves, clear cells, solve the puzzle, or quit the game.
